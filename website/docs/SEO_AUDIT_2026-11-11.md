## Fixed in code

1. **Titles cut off in search results.** The root template appended ` · Web3Chess` to every article title, so 29 pages exceeded 60 characters. `fitTitle()` in `src/lib/seo.ts` drops the suffix only when it would push a title past 60, or when the title already names the brand (`/CREATIVES` read "…Web3Chess Campaign Graphics · Web3Chess").
2. **Meta descriptions.** `/play` (166) and `/how-it-works` (175) trimmed to 154 and 155 characters.
3. **`/play` was a dead end for crawlers.** It had no site footer and 3 internal links, although it is the page for "telegram chess bot". It now renders the shared `Footer` (13 links on the live page).
4. **Home H1 read "Play chessWin real crypto"** to any crawler that reads HTML without CSS (two block spans, no space). A space now separates them.
5. **`llms.txt` contradicted the site.** It listed stakes 1–250 USDT while the Wagers page showed 1, 5, 10 and 25, and it promised "instant non-custodial withdrawals" (withdrawals need a Telegram confirmation and the platform holds balances). AI answer engines read this file, so wrong money claims would be repeated to users. Rewritten from the live Wagers page and `MATCH_RULES`/`WAGER_TIERS`, with 18+ and "can lose their stake", and the keyword list removed. **Correction:** the website's 1/5/10/25 tiers were themselves out of date; the app's lobby offers presets from 1 to 1,000 USDT plus custom amounts, and `llms.txt` and the Wagers page were updated to match in #98.
6. **Meta keywords stuffing on articles.** Single slug words ("can", "you", "if") were listed as keywords. Removed.
7. **HSTS.** `Strict-Transport-Security: max-age=31536000` on the website, so repeat visits skip the http→https redirect (PageSpeed measured 601 ms for it on mobile). Not `includeSubDomains`; `preload` is a separate decision.
8. **IndexNow.** Key file `public/4c121be8e56adb6686d9b061c044d9fa.txt` and `npm run seo:indexnow` (submits the live sitemap, or given paths, to Bing, Yandex, Seznam, Naver and Yep). The script refuses to run until the key file is live. Bing's index also feeds Copilot, ChatGPT search and DuckDuckGo.

Verified on a production build: typecheck, ESLint on changed files, `npm run build` (content and UI checks), `npm run seo:check` (46 pages), HSTS header and key file served, unknown article still returns 404, `/play` footer rendered with no console errors.

## The real bottleneck is off-site

On-page SEO was already good. What holds traffic back:

- **Domain Rating 0.** No referring domains Ahrefs counts. Without links, new pages rank for almost nothing competitive.
- **Not visible in Bing-based search.** A `site:web3chess.online` search returned no pages from the domain.
- **Google (Search Console, read 2026-11-12, domain property):**
  - Performance, 22 Sep–10 Nov: 3 clicks, 85 impressions, average position 38.4. Last 28 days: 2 clicks, 67 impressions, position 42.7. Top query `web3 chess` (7 impressions, 0 clicks); the rest are single impressions, several for "3 player chess online", which the site does not offer. Legacy `www.web3chess.online/` still carries the most impressions (31) until Google recrawls the redirect.
  - Indexing: 21 indexed, 66 not indexed. Indexed website pages are only Home, Play, Academy, How It Works, Wagers and `/blog/can-you-make-money-on-chess-com`; the rest are app login/home pages and legacy `www` URLs that now redirect.
  - **Discovered – currently not indexed (39):** `/blog`, `/CREATIVES` and nearly every article, all with no crawl date. Google knows the URLs from the sitemap but has not fetched them. On a new domain with no links this is a crawl-priority problem, not a markup problem: Home already links `/blog` and 8 articles.
  - Crawled – currently not indexed (7): `/blog/fair-play-in-web3-chess` (crawled 10 Nov), four app pages (`/zh/marketplace`, `/de/academy`, `/de/game`, `/zh/academy`), `www/ru`, and a font file.
  - Not found (11): legacy `www` locale and login paths (all now redirect to the app, verified), `app.web3chess.online/academy` (still 404) and `web3chess.online/&` (a malformed link). Harmless.
  - `/rules`, `/fair-play`, Terms and Privacy are not in the index yet.
  - Sitemap: submitted 12 Oct, last read 9 Nov, status Success, 46 discovered pages. URL Inspection still says "No referring sitemaps detected" for unindexed URLs; that field only updates after Google crawls the URL.
  - **Indexing requested on 2026-11-12** (URL Inspection → Request indexing, all confirmed "added to a priority crawl queue"): `/rules`, `/blog`, `/fair-play`, `/blog/can-you-castle-if-rook-is-attacked`. All four were "URL is unknown to Google" before the request. Re-inspect them around 2026-11-19.

Order of work, highest leverage first:

1. After deploying this branch, run `npm run seo:indexnow` once, then for each new or updated article (`npm run seo:indexnow -- /blog/<slug>`).
2. Verify the domain in Bing Webmaster Tools (it can import the Google Search Console property) and submit the sitemap. Needs the owner's Microsoft or Google sign-in.
3. In Search Console, request indexing (URL Inspection, about 10 per day) for the unindexed pages that answer a real query: `/rules`, `/blog`, `/fair-play`, then the articles with a specific question in the title, such as `/blog/can-you-castle-if-rook-is-attacked`.
4. Earn first links from places the audience already is. Each listing must follow that site's rules, must not promise winnings, and needs the owner's account and approval:
   - **Telegram Apps Center**: Telegram's main Mini App catalog; third-party guides say submissions go through `@app_moderation_bot`. Check its rules on real-money games first.
   - **TON App catalog (ton.app)**: per its official channel, sign in with Telegram, open the profile and choose "Add App"; manual moderation, free base listing.
   - **FindMini** and **DappRadar**: crypto-focused app directories.
   - Chess communities: share an Academy position, not a sales pitch.
   - The GitHub repository README, linking to the site.
5. Keep the existing loop from `SEO_GROWTH_OPERATING_SYSTEM_2026-10-15.md`: one page improvement per week, chosen from settled Search Console query data.

No SEO program can guarantee a traffic number; measure impressions, clicks and website-sourced registrations by complete weeks.

## Flagged, not changed (needs an owner decision)

- **Consent defaults.** `layout.tsx` sets Google Consent Mode defaults to `granted` for ads and analytics before any user choice. For visitors in the EEA/UK that is likely non-compliant. Fix with a consent banner, or default to `denied`.
- **Copy that may overstate the product:** "Sub-Second Finality" and "Automated Match Escrow" on `/play`, "Instant Credit" and the FAQ heading's "non-custodial crypto withdrawals" on `/wagers`, "GRAM wallet routing" in the Privacy description. Check against the current backend before changing.
- `/CREATIVES` is in the sitemap with an uppercase URL. Fine if the studio is meant to be public; otherwise remove it from `sitemap.ts` and add `noindex`.
